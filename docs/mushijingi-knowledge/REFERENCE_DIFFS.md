## 2. スコープ拡張が必要な項目

### 色

- 既存 `MUSHI_MANUAL.md` は「スターター〜第1弾の基本色」として赤・青・緑を定義しており、そのスコープ内では正しい。
- 第4弾で無色が加わるため、全弾対応エンジンでは `COLORLESS` が必要。
- 無色を三すくみへ追加するのではなく、基本の色有利倍率を発生させない独立値として扱う。

### 所有者と操作者

- 既存資料のゾーン定義はプレイヤーごとのDECK/HAND/FOOD/FIELD/DISCARDを持つが、`ownerId` と `controllerId` の分離は明文化されていない。
- 第2弾エメラルドゴキブリバチ以降、相手所有カードを一時的に自分の場で操作するため必須。

### 特性の全ゾーン無効化

- 既存資料は特性を通常技から分離しているが、現在有効な特性集合を動的に再計算する機構は未定義。
- 第4弾カイコの `＜くちなし＞` は両者の全ゾーンにある虫の `＜＞` 技を失わせるため、場だけの継続効果では不足する。

### 遅延効果とインスタンス追跡

- 既存資料は裏向きがFIELD離脱ではないこと、場を離れた時のクリーンアップを定義しており方向性は一致。
- 第2〜7弾では「発動済み効果は発生源が特性を失っても残る」「場を離れて別の場へ出ると旧効果が消える」「複数個体を追跡する」が増えるため、明示的な `DelayedEffect` と `trackedInstanceIds` が必要。

### コスト

- `food.length != availableCost` と、メイン開始後のエサ増減でコストを再計算しない既存記述は、第4弾マンディブラリスフタマタクワガタ公式裁定と一致。
- 追加で、印刷コスト、現在の支払額、別カード効果が参照する元コスト、0コスト支払い、コストを支払わない登場を分離する必要がある。

### ダメージと破壊

- 既存資料はダメージ計算と破壊を記述しているが、ダメージ0と直接破壊の明示的な別イベントは未定義。
- 第2弾ジョロウグモ公式裁定により、ダメージを0にする効果は「破壊する」効果を無効にしない。
- 第7弾では「与える/できる」と「受けない/できない」の競合時に否定側を優先する一般優先規則が必要。

### デッキ同名制限

- 既存資料は第7弾URリメイクを含まない。
- 第7弾公式Q&Aにより、同名異能力・異番号・異レアリティでも同じ `canonicalName` の合計は2枚まで。
- `（幼虫）`、`（女王）` 等を含む名称は別名として各2枚まで。

### レアリティ

- 既存カタログのレアリティ集合に第7弾の `UR` がない。
- 第7弾8枚に `UR` を確認したため、表示・検索・シリアライズの列挙へ追加が必要。

## 4. 一致を確認した重要項目

- 表裏変更はFIELD離脱ではなく、表向きに戻っても登場時効果を再発動しない。

- エサ増減と発生済みコストを分ける。
- 生物分類 `taxonomy.family` はフレーバーではなく効果参照データとして扱う。
