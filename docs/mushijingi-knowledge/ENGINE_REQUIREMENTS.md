# 蟲神器 第2〜7弾 横断エンジン要件

> 対象: `SET2_CATALOG.md`〜`SET7_CATALOG.md`（371種）  
> 優先順位: 公式Q&A > カード表面情報 > 非公式DB探索情報  
> 目的: 個別カードのif文を増やすのではなく、再利用可能なゲーム機構として実装する。

## 1. 必須データモデル

```ts
type CardDefinition = {
  definitionId: string;       // 弾・番号を含む印刷物ID
  canonicalName: string;      // デッキ同名制限に使う名前
  printedCost: number;
  printedColor: "RED" | "BLUE" | "GREEN" | "COLORLESS" | null;
  type: "INSECT" | "ENHANCEMENT" | "TECHNIQUE";
  family: string | null;
  skills: SkillDefinition[];
  traits: TraitDefinition[];
};

type CardInstance = {
  instanceId: string;
  definitionId: string;
  ownerId: string;            // 対戦開始から変わらない
  controllerId: string;       // 場での現在の操作者
  zone: Zone;
  face: "FACE_UP" | "FACE_DOWN";
  damage: number;
  attachments: string[];
  counters: Record<string, number>;
  oncePerStayUsed: Set<string>;
  appliedEffects: AppliedEffect[];
};
```

`canonicalName` と `definitionId` を分ける。第7弾URリメイクは能力・番号が違っても同名制限を共有する一方、`（幼虫）` や `（女王）` が付く別名カードは別名として扱う。公式第7弾Q&Aでは、SRとURの「カブトムシ」は合計2枚まで、名称が異なる成虫/幼虫等はそれぞれ2枚までとされる。

## 2. イベントと解決キュー

最低限、次のイベントを型として持つ。

```text
CARD_USE_DECLARED
COST_PAID
CARD_USE_NEGATED
ENTERED_FIELD
ATTACK_DECLARED
SKILL_EFFECT_RESOLVED
DAMAGE_WOULD_BE_DEALT
DAMAGE_DEALT
DESTROY_WOULD_OCCUR
DESTROYED
LEFT_FIELD
TERRITORY_WOULD_BE_DRAWN
TERRITORY_DRAWN
TURN_END_STARTED
TURN_END_FINISHED
```

- 攻撃、効果、コスト、状態起因の破壊原因を `cause` に保持する。
- 「同時に発揮」はキューへ積み、ターンプレイヤー側、非ターンプレイヤー側の順で、各プレイヤーが自分の処理順を選ぶ。
- 解決時に対象や発生源が場を離れていた場合、カードごとの追跡方式に従い不発または継続を決める。
- 第7弾カブトムシの裁定では、ターン終了時の複数破壊を選択順で解決し、先に代替破壊されたカードへ残る後続処理は対象消失で不発になる。

## 3. 機構別要件

### 3.1 裏向き

- `face` は `zone` と独立させる。表裏変更はFIELD離脱ではない。
- 場の裏向き虫は「いないもの」として合法対象・特性・攻撃先判定から外すが、同一 `instanceId` は維持する。
- 裏向きエサはコスト数には含むが、色とカード種別を失い、原則として効果対象に選べない。
- 表向きへ戻っても `ENTERED_FIELD` は発火しない。

カード例:

- 第2弾1/55 リュウジンオオムカデ: すくい投げで裏→表になっても `＜翡翠色＞` は再発動しない。
- 第3弾6/60 マダラサソリ: 「弱毒針」はダメージ前に相手エサを裏向きにでき、破壊や縄張り取得がなくても処理する。
- 第4弾16/64 マンディブラリスフタマタクワガタ: 裏向きエサしかない場合、エサ破壊を実行できず自身が破壊される。

### 3.2 所有者と操作者

- `ownerId` は不変、`controllerId` は場の支配だけを表す。
- 他人のカードがHAND/DISCARD/FOOD/DECKへ移る場合は、原則として所有者側の該当ゾーンへ移す。
- 一時支配後にFIELDを離れて再登場したら新しい場の個体として扱い、以前の遅延効果を切る。

カード例:

- 第2弾7/55 エメラルドゴキブリバチ: 「操り針」で相手虫を自分の場へ出すが、手札・捨て札・エサ・山札は元の所有者側へ戻る。操った虫の登場時効果は発火する。
- 第4弾31/64 カヤキリ: `＜かばう＞` で得たターン終了時帰還は、操り針で別の場へ出し直されると消える。
- 第6弾63/64 贄虫の転生: 相手所有の操り虫は「自分の山札の下」へ置けないため対象不適格。

### 3.3 色と色変更

- `printedColor`、現在色、期限付き色変更を分離する。
- 第4弾から `COLORLESS` を正式な色として扱う。無色は基本の三すくみ倍率を発生させない。
- エサ場での色変更はFIELD移動後へ引き継がない。
- 変更対象のスナップショット、期限、発生源を保持する。

カード例:

- 第2弾1/55 リュウジンオオムカデ: 登場時に青/緑へ、ターン終了時まで変更。
- 第3弾24/60 ニジイロクワガタ: 全エサの色を変更するが、訂正後裁定では裏向きエサを含まない。
- 第4弾43〜45/64: カイコ、オカダンゴムシ、ヒジリタマオシコガネが無色虫。
- 第7弾20/64 カブトムシ: 「王者のツノ」の2倍は通常の色有利倍率と重ねて4倍にせず、無欠の息吹の「受けない」が優先される。

### 3.4 エサとコスト

- `foodCount` と `availableCost` を分離する。メイン開始時のコスト発生後にエサが増減しても再計算しない。
- エサは表裏、印刷色、現在色、カード種別を持つ独立インスタンスとする。
- `printedCost`、現在の支払額、効果が参照するコストを分ける。特記がなければカード効果は元の印刷コストを参照する。
- コスト増減は差分を合算してから元コストへ適用し、最低0とする。
- 「コストを支払わずに使用/場に出す」と「0コストを支払う」は区別する。

カード例・裁定:

- 第2弾51/55 白夜の羽化: 幼虫をエサへ置くが、その追加エサのコストは当ターン発生しない。
- 第3弾16/60 パラワンオオヒラタクワガタ: `＜樹液酒場＞` で実支払額が下がっても、入れ替え効果は印刷コスト6を参照する。
- 第4弾16/64 マンディブラリスフタマタクワガタ: 登場後にエサを破壊しても、発生済み `availableCost` は減らない。
- 第6弾ゴクラクトリバネアゲハ: 効果で0まで下がったカード自身の0コストを支払うことは「コストを支払った」に含むが、別カードの効果で場へ出ることは含まない。

### 3.5 捨て札とゾーン移動

- 移動APIは `move(instanceId, from, to, cause, ownerPolicy)` とし、破壊と単純移動を分ける。
- 「破壊されるとき」の置換は、山札下・手札・エサへの移動では発火しない。
- 装着先が場を離れたら強化を捨て札へ送るが、移動と破壊の順序をイベント化する。
- 場を離れた個体に与えられた期限付き効果は原則消える。カードが明示的にインスタンスIDを追跡する場合だけ継続する。

カード例:

- 第3弾48/60 白銀蜘蛛の糸: 2体を捨て札から出し、強化破壊時にその2体を追跡して破壊する。途中で場を離れた個体や入れ替わった新個体は対象外。
- 第6弾63/64 贄虫の転生: 山札下への移動は破壊ではないため、空蝉の皮鎧の破壊置換を使えない。

### 3.6 登場時・破壊時・縄張り

- `ENTERED_FIELD` は手札からの通常登場だけでなく、術・技・縄張り・捨て札・エサから場へ出た時も発火する。
- 表向きへ戻るだけでは発火しない。
- 破壊原因を保持し、「虫の攻撃で破壊」「技効果で破壊」「コスト/条件で破壊」を判別する。
- 縄張り取得は虫の攻撃で虫が破壊された後、または直接攻撃時。破壊時誘発との順序は公式裁定に従う。

順序例:

- 第3弾11/60 サシハリアリ: 縄張りを引いた後に相手が手札を捨てる。
- 第3弾17/60 サタンオオカブト: 虫の攻撃で破壊された時、相手の手札破棄は縄張り取得より前。
- 第2弾7/55 操り針: 破壊した相手虫を自分の場へ出し、その登場時効果を処理してから相手が縄張りを引くケースがある。

### 3.7 攻撃制限と攻撃誘導

- `canAttack`、`canBeAttacked`、`mustBeAttackedIfPossible`、直接攻撃可否を分ける。
- `＜鳴く＞`、`＜りんぷん＞`、`＜かばう＞` 等は同じ「攻撃誘導候補集合」へ統合し、複数種類がある場合はその集合から選ぶ。
- 術の対象可否は虫の攻撃対象制限と別判定。
- 「攻撃できない状態」は発生源が失われても残るものと、継続特性に依存するものを区別する。

カード例:

- 第4弾31/64 カヤキリ: `＜かばう＞` で出た時だけ誘導とターン終了時帰還を得る。通常登場時には得ない。
- 第5弾ヤエヤマツダナナフシ: `＜単為生殖＞` で出した虫の「このターン攻撃不可」は、発生源が特性を失っても残る。
- 第4弾43/64 カイコ: `＜くちなし＞` で継続特性そのものを失えば、オオコノハムシの `＜擬態＞` による攻撃不可は解除される。

### 3.8 遅延効果

```ts
type DelayedEffect = {
  effectId: string;
  sourceInstanceId: string | null;
  trackedInstanceIds: string[];
  expiresAt: EventPoint;
  persistsIfSourceLeaves: boolean;
  requiresTrackedInstanceInZone?: Zone;
};
```

- 「ターン終了時」「次の相手ターン」「次にダメージを受けた時」を別トリガーにする。
- 発動済みの遅延効果と、場にいる間だけ有効な継続効果を分ける。
- 同じ個体が表裏変更しても追跡を維持し、FIELD離脱・再登場では旧追跡を切る。

カード例:

- 第2弾50/55 口寄せの時蛹: 次の相手ターン終了時に強化自身を破壊する。
- 第2弾7/55 操り針: ターン終了時に一時支配した虫を破壊するが、羽化等で別ゾーンへ移れば旧遅延効果は不発。
- 第4弾31/64 カヤキリ: `＜かばう＞` 発動済みの帰還は、後から `＜くちなし＞` を受けても消えない。

### 3.9 代替コスト・代替破壊・打ち消し

- コスト支払いと効果解決を別トランザクションにする。使用が打ち消されても支払済みコスト・代替コストは戻さない。
- 代替コストは `paymentKind` を持ち、通常コスト増減の影響を受けるかをカードごとに指定する。
- `DESTROY_WOULD_OCCUR` で代替破壊を選択し、元の破壊が起きなかったことをイベント結果に残す。

カード例:

- 第3弾51/60 刺蠅の血盟: コストの代わりに縄張り2枚を捨て札へ置ける。第7弾Q&Aでは、その後カードを打ち消されても支払った縄張りは戻らない。
- 第3弾29/60 ヨーロッパミヤマクワガタ: 幼虫破壊を条件にコストを支払わず場へ出る。
- 第7弾ユカタンビワハゴロモ: 術を打ち消す前に支払われたコストは返還しない。空蝉の皮鎧による自身の破壊置換を利用しても打ち消しは成立する。

### 3.10 ダメージと破壊の分離

- `preventDamage` と `preventDestroy` を別機構にする。
- AP0の攻撃も攻撃として成立し、1回限りのダメージ無効を消費し得る。
- 「ダメージを受けない/0にする」は「破壊する」効果を止めない。
- `can` と `cannot` が同時なら `cannot` を優先する。

カード例:

- 第2弾4/55 ジョロウグモ: 蜘蛛の巣は術ダメージも0にするが、退魔の蚊遣火の直接破壊は止めない。0ダメージになった毒は蓄積しない。
- 第2弾47/55 蚰蜒の足切り: 虫攻撃ダメージだけを0にし、術ダメージは対象外。
- 第7弾20/64 カブトムシ: 全色へ2倍を与える効果より、無欠の息吹の「色による2倍を受けない」が優先。

### 3.11 特性の付与・喪失と全ゾーン効果

- 技/特性を定義配列から直接読むのではなく、現在の有効スキル集合を計算する。
- 効果によるスキル付与・喪失は、場だけか全ゾーンかを明示する。
- 既に解決済みの効果と、発生源の特性が継続している間だけ有効な効果を分ける。

カード例:

- 第4弾43/64 カイコ: `＜くちなし＞` は両者の場・手札・エサ・縄張り・捨て札にある虫の `＜＞` 技を失わせる。強化カードの特性は失わせない。
- 第3弾48/60 白銀蜘蛛の糸: 出した2体はキーワード名を含む `＜＞` 技そのものを失う。
- 第4弾飛蝗の待ち伏せ: バッタ科・イナゴ科へ `＜とびだす＞` を付与するため、分類データをゲームロジックから参照する。

## 4. デッキ構築と識別子

- 収録弾・番号・レアリティが異なる同名カードを同一 `canonicalName` に束ねる。
- デッキ上限は `canonicalName` ごとの合計2枚。
- `カブトムシ` と第7弾UR `カブトムシ` は合計2枚。
- `ナミアゲハ` と `ナミアゲハ（幼虫）`、`スズメバチ` と `スズメバチ（女王）` は別名なので各2枚。
- UIは同名異能力カードを区別するため、必ず弾・番号・レアリティも表示する。

## 5. 実装優先順位

1. CardDefinition / CardInstance / owner-controller / zone-face 分離
2. イベントキュー、破壊原因、遅延効果、対象再確認
3. コスト台帳、印刷コスト/実支払額、エサ表裏
4. 攻撃合法対象とダメージ/破壊置換
5. 特性の付与・喪失、全ゾーン継続効果
6. デッキ同名制限と第7弾UR識別
7. カード個別効果を上記プリミティブへマッピング
