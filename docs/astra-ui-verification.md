# astra-ui-redesign 実装・確認記録

2026-09-18。作業場所: `C:/Users/aatot/mushi-mobile`。main には変更・マージを行っていない。

## 1. 調査した現状
vanilla JavaScript の静的アプリ。対戦、CPU、端末受け渡し、チュートリアル、カード501種の図鑑、デッキ編集・保存・対戦受け渡しを確認した。画面は2つのHTMLに分離し、カードが文字主体、検索項目が常時展開、補助ゾーンのタップ領域が小さい構成だった。ルール層、カード定義、保存データ形式を維持した。

## 2. デザイン
「夜の森で開く、蟲の標本帖」。墨緑、生成り、真鍮色の罫線、明朝見出しを共通化。ホーム→図鑑→デッキ→対戦を同じカード画像とナビゲーションでつなぐ。対戦の数値は既存エンジンの現在値を使い、画像に印刷された元の値とは分けて表示する。図鑑は所持カードではなく登録カードの一覧。

## 3. 参考
公式紹介ページ・公開画面から設計思想を抽出した。実際に各ゲームをプレイした比較ではない。
- [Pokémon TCG Pocket](https://www.pokemontcgpocket.com/): カード中心の閲覧と拡大。
- [MARVEL SNAP](https://marvelsnap.com/): 縦画面でカードと少数の重要数値に集中する情報設計。
- [Shadowverse: Worlds Beyond](https://shadowverse-wb.com/en/system/cardbattle/battle/): 両者の場・リソース・ターン操作・履歴の分離。
- [MASTER DUEL](https://www.konami.com/yugioh/masterduel/jp/ja/): 詳細を必要な場面で開く盤面整理。

## 4. 主要変更
- モード選択をカードが主役のホームに再構成。図鑑・デッキへ直接移動。
- 図鑑を2列の画像グリッドに変更。検索・7種のフィルターを維持し、フィルターを折り畳み。501種の画像を参照ページに対応付け。
- 下から開く観察シート、採用枚数、追加通知、編集中デッキへのショートカット。
- デッキ内のカード画像、枚数調整、種類内訳、コスト分布、対戦可否、保存前の離脱確認。保存失敗時は対戦へ遷移しない。
- 対戦では両者の場、手札、コスト、縄張り等の枚数を分離。エサ・捨て札は拡大して全枚数を確認・選択可能。
- 選択可能な手札、効果の対象を含むゾーン、直接攻撃先、複数選択済みカードを表示。
- キーボードフォーカス、ダイアログの閉じる操作、背景の操作防止、ズーム禁止の解除、動き軽減設定への対応。

## 6. 発見し修正した問題
- 図鑑での追加・上限通知が非表示のデッキ画面にしか出なかった。
- 場の裏向きカードが表面表示のままだった。描画をカード裏面へ修正（既存の詳細参照ルールは変更なし）。
- エサ配置・通常召喚後に操作のない詳細画面が残った。
- CPU戦のターン終了で対人戦用の端末受け渡し表示が出た。再現する回帰テストを追加してCPU時のみ抑止。
- 再描画後に元のカードDOMが消え、キーボードフォーカスが失われた。
- チュートリアル案内が相手の場を圧迫した。下部操作域へ移動し、短い縦画面は情報行を圧縮。
- チュートリアル勝利後の操作が背景側に残った。結果パネルへ統合し、再実行ボタンのイベント伝播による二重開始も修正。
- 直接攻撃・効果対象の強調が非表示の補助カードだけに付いた。表示中のゾーンへ強調を移した。

独立した読み取り専用コードレビューを2回実施。指摘されたフォーカス喪失を修正し、再レビューで重大な追加問題なし。

## 7. 残る制約
- カード画像は既存資料の参照先である非公式サイト mushijingi.com の外部配信に依存する。失敗時の代替表示は実装・検証済み。出典は `shared/card-art-manifest.js`。
- 対戦未対応のカードは既存の対応状況を維持しており、図鑑閲覧と構築時の表示に留まる。今回のUI変更でカード効果を新規実装していない。
- 実機iOS Safari、Android端末、画面読み上げソフトでの検証は未実施。ブラウザのモバイル相当サイズでの確認。
- 音声、オンライン対戦、実際の所持・獲得管理は既存機能に含まれず、今回追加していない。
