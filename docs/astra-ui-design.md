# 蟲神器 UI/UX 再設計

作業ブランチ: astra-ui-redesign。ゲームエンジン、ルール、カード定義、保存形式は維持する。

## 現状
静的HTML + vanilla JavaScript。index.html はCPU／端末受け渡し対戦・チュートリアル、toolbox.html は全カード検索・詳細・20枚デッキ編集・保存・対戦への受け渡し。カード表示は文字のみ。図鑑の追加通知は非表示のデッキ画面にあり、フィルターが初期画面を占める。対戦は極小の補助ゾーンに公開カードが並ぶ。既存テストは464件成功。

## 方針と比較
1. 既存CSSだけを変更: 低リスクだが体験の分断が残るため不採用。
2. 既存エンジンの上に共通のカード表現、ナビゲーション、観察シートを設ける: 採用。
3. SPAへの全面移行: 移行リスクが大きく今回の目的には不要。

「夜の森で開く、蟲の標本帖」。墨緑・生成り・真鍮、明朝の見出しと可読性の高い本文。カード画像を主役にし、和の静けさは余白と罫線で表現する。図鑑は所有数を示さず登録カードを閲覧する。未対応カードは閲覧専用と明示する。

## 参考（公式の紹介画面・解説を調査）
- Pokémon TCG Pocket: カードを眺めるグリッドと拡大、収集から構築への導線。https://www.pokemontcgpocket.com/
- MARVEL SNAP: カードと少数の数値を中心とする画面、縦画面で下部に操作を集める。https://marvelsnap.com/
- Shadowverse: Worlds Beyond: 自分と相手の位置、場、リソース、履歴の階層。https://shadowverse-wb.com/en/system/cardbattle/battle/
- MASTER DUEL: カードの詳細と盤面を分け、複雑な情報を必要な時に開く。https://www.konami.com/yugioh/masterduel/jp/ja/
実機をプレイしての比較ではなく、公開情報から本アプリへ適用する設計判断。

## 実装単位
- shared/card-visuals.js と画像マニフェスト: 既存資料の参照先である非公式カード検索サイト mushijingi.com のカード画像、失敗時の明示的な代替表示。ルール値は既存定義から表示。
- css/design-system.css: 色・文字・フォーカス・動き軽減の共通基盤。
- index.html / css/astra-battle.css / js/ui/battle-experience.js: 対戦入口、盤面、補助ゾーン閲覧、ダイアログ操作。
- toolbox.html / toolbox/toolbox-v1-app.js / toolbox/astra-toolbox.css: 画像グリッド、折り畳み検索、デッキ統計、通知、ナビゲーション。
- tests: 既存464件、共有データテスト、ブラウザで360/390/430px縦画面・横画面・デスクトップを確認。

## 制約
mainを変更しない。未追跡資料を変更しない。非公開カード情報を漏らさない。CPU判断とカードルールを変更しない。既存localStorageキー・デッキ形式を維持。新規フレームワーク不要。画像の出典を記録し、取得失敗でも名前と数値で操作可能とする。

## 実装・検証計画
- [x] 共通ビジュアルと入口: 画像501種の対応を参照ページから抽出し、共通テーマとモード選択を実装。
- [x] 図鑑・デッキ: 検索→詳細→追加→枚数調整→保存→再読込→対戦を確認。20枚・同名2枚制約を維持。
- [x] 対戦: 公開ゾーンの拡大閲覧、カード詳細、行動状態、手札と場の視認性を実装。CPU・対人・チュートリアルを確認。
- [x] 品質: 既存テスト、ブラウザエラー、画面内収まり、ダイアログ、画像失敗時、横向きを確認して修正。結果は astra-ui-verification.md を参照。

画像は外部ホストから遅延読込する。ローカルへ複製しない。画像の権利は各権利者に帰属し、画像URL・参照ページは shared/card-art-manifest.js に記録している。取得時に第一弾の参照パスが MUSHI1 ではなく MUSHI であることを確認し訂正した。
